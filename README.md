# Sofia 桌面时钟

一个运行在 Windows 桌面上的圆形时钟。它把时间、天气、日程提醒和语音播报放在一个轻量窗口中，适合放在桌面边缘持续查看。

> 当前仓库公开的是 Python 源码。新闻数据库、提醒日程和平台地址由使用者自行配置；仓库不提供私人服务、账号或新闻内容。

## 功能

### 桌面时钟

- 显示模拟表盘和数字时间，秒针平滑移动。
- 拖动表盘移动窗口，拖动边缘调整大小。
- 调整窗口透明度，减少对其他桌面内容的遮挡。
- 鼠标悬停时显示操作控件；可从菜单配置报时和提醒。

### 报时与语音

- 选择每 15 分钟、每 30 分钟、每小时或自定义间隔报时。
- 使用 Windows SAPI 语音引擎播报时间、天气和已配置的新闻。
- 按作息提醒播放提示音；可在提醒编辑器中修改时间、文字和音频文件。
- 支持开启或关闭报时、日程提醒、天气播报和新闻播报。

中文语音质量取决于 Windows 已安装的语音。若系统没有中文语音，文字播报可能使用其他可用声音或无法启动；表盘和提示音功能仍可使用。

### 天气

- 支持在城市列表中切换城市，也可搜索城市。
- 显示当前天气；菜单中可查看今日详情和一周预报。
- 按顺序尝试中国天气网页面、中国天气网接口、wttr.in 和 sojson 等来源，并缓存成功结果、在来源故障时切换备用来源。
- 天气数据来自第三方网络服务。服务接口、页面结构和可用地区由服务提供方决定，变更后天气功能可能暂时不可用。

### 新闻浏览和播报（可选）

- 可连接使用者自己的 MySQL 数据库，读取含 `id`、`keyword`、`info` 字段的新闻表。
- 新闻浏览器支持调整显示条数；语音播报可配置时段、间隔和单次条数。
- 按新闻记录 ID 保存已播报记录，减少重复播报。
- 没有配置数据库时，新闻功能默认关闭，时钟、天气和本地提醒仍可使用。

本项目不提供数据库、新闻抓取服务或新闻内容。连接数据库前，请确认自己拥有相应访问权限，并遵守数据来源的使用规则。

## 环境要求

- Windows 10 或 Windows 11；其他系统未验证。
- Python 3.9 或更高版本，安装时勾选 **Add Python to PATH**。
- Windows Python 安装包应包含 Tkinter。语音播报使用 Windows SAPI。
- 联网天气功能需要可访问相应的天气服务。

## 安装与运行

在项目目录打开 PowerShell：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python ".\带天气预报的时钟v1.90.py"
```

首次运行时，程序会在当前工作目录创建 `config.ini` 和 `reminders.ini`。请从项目目录启动程序，以便程序能找到铃声和配置文件。若 PowerShell 不允许激活虚拟环境，可以直接运行：

```powershell
.\.venv\Scripts\python.exe ".\带天气预报的时钟v1.90.py"
```

第三方包也可单独安装：`requests`、`beautifulsoup4`、`pyttsx3`、`pygame`、`PyMySQL`、`watchdog`、`markdown` 和 `html2text`。`requirements.txt` 另含 PyInstaller 打包依赖。

## 基本操作

- **选城市**：左键点击城市名称循环切换；滚轮切换；右键打开城市菜单；使用搜索项定位城市。
- **移动与缩放**：拖动表盘空白处移动；拖动表盘边缘调整大小。
- **透明度**：使用表盘右侧的透明度控件调整。
- **报时**：左键切换开关；右键选择刻点、半点、整点或自定义间隔。
- **提醒**：通过右键菜单打开提醒编辑器。每条提醒占三行，依次为时间、提醒文字、铃声文件名。
- **天气**：打开天气菜单查看当前天气、今日详情和一周预报；可单独开关天气语音播报。
- **配置刷新**：编辑 `config.ini` 或 `reminders.ini` 后，程序会监视文件变化并刷新设置。
- **新闻**：需要先配置 MySQL 连接。未配置时，新闻自动播报保持关闭。

## 配置

### 城市

`config.ini` 的 `[city_mapping]` 区域采用“城市名称 = 天气城市代码”格式。程序自带常见城市示例。可以复制 `config.ini.example` 为 `config.ini` 后增删城市；首次运行自动创建的配置文件也可以直接编辑。

### 提醒

`reminders.ini` 每条记录必须恰好包含三行：

```text
08:00
开始一天
dingdong.mp3
```

时间使用 24 小时制，铃声文件应位于程序工作目录，或填写可访问的音频文件路径。`reminders.ini.example` 提供了不含个人作息信息的示例。个人日程、学校课表和家庭安排请保存在本机配置中，不要提交到公开仓库。

### 育儿与家庭作息

提醒表可以按孩子和家庭的实际节奏设置，例如起床、早餐、出门、放学接送、阅读、运动、晚餐和睡前准备。每个提醒只提示约定的时间和事项，家长可以随季节、年龄和当天安排调整，不必照搬示例时刻表。使用前先把提醒文字改成家庭自己的表达，并检查铃声音量和提醒时间。

### 可选新闻数据库

在本地 `config.ini` 中增加以下内容。示例中的空值需要替换成本人有权使用的数据库设置：

```ini
[news_database]
host = 数据库主机
user = 数据库用户名
password = 数据库密码
database = 数据库名称
port = 3306

[links]
sofia_platform_url = https://你的平台地址
```

也可通过环境变量设置连接信息，环境变量优先于 `config.ini`：

```powershell
$env:SOFIA_NEWS_DB_HOST = "数据库主机"
$env:SOFIA_NEWS_DB_USER = "数据库用户名"
$env:SOFIA_NEWS_DB_PASSWORD = "数据库密码"
$env:SOFIA_NEWS_DB_NAME = "数据库名称"
$env:SOFIA_NEWS_DB_PORT = "3306"
$env:SOFIA_PLATFORM_URL = "https://你的平台地址"
```

数据库表须包含 `id`、`keyword`、`info` 三列。默认表名为 `info`，也可在程序菜单中填写其他表名。配置文件 `config.ini` 已加入 `.gitignore`，不要删除该忽略规则或把凭据写入源码。

## 常见问题

**窗口没有中文语音？** 进入 Windows 的语音设置安装中文语音；也可以检查系统是否启用了语音输出设备。

**没有天气信息？** 检查网络和城市代码，稍后重试。程序会更换天气来源，但第三方服务不可用时不会有实时天气。

**没有铃声？** 确认 `pygame` 安装成功，并确认 `dingdong.mp3` 与程序的工作目录相同；在提醒编辑器中检查铃声文件名。

**新闻列表为空？** 新闻读取是可选功能。检查 `[news_database]` 是否完整、数据库是否可访问，以及表中是否存在 `id`、`keyword`、`info` 字段。

**能否直接下载 exe？** 目前仓库发布源码，没有承诺提供适用于所有 Windows 环境的预编译 exe。可在本机按 `requirements.txt` 安装后运行源码。PyInstaller 打包需要在目标 Windows 架构上自行构建，并将图标、铃声和本地配置一并按需部署。
